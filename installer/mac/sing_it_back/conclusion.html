Merci ! C’est installé.

Dans Ableton Live : Réglages → Plug-Ins → Rescan. Sing It Back apparaît dans les effets audio : Plug-Ins → VST3 / Audio Units → LALZIN. Glisse-le sur une piste de voix.

Astuce : règle d’abord le ton et la gamme du morceau (barre du bas), puis monte CROWD. Mappe le knob sur ton contrôleur (premier paramètre « Crowd ») pour faire entrer le public sur les refrains. Double-clic sur le knob = retour à 25 %.
