Merci ! C’est installé.

Dans Ableton Live : Réglages → Plug-Ins → Rescan. Boogie Trio apparaît dans Plug-Ins → VST3 / Audio Units → LALZIN.

Astuce : mappe le knob sur ton contrôleur MIDI (mode MIDI Map d’Ableton, premier paramètre « Amount »). Double-clic sur le knob = retour à 0 % (solo).
