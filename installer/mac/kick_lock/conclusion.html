Merci ! C’est installé.

Dans Ableton Live : Réglages → Plug-Ins → Rescan. Kick Lock apparaît dans les effets audio : Plug-Ins → VST3 / Audio Units → LALZIN.

Le kick : Kick Lock sur la piste de basse, Kick Lock Send sur la piste du kick (VST3 ou AU, sans routage). Lance la lecture : Send affiche LINKED, Kick Lock affiche LOCKED · LINK. Sans Send, Kick Lock suit le tempo (LOCKED · BEAT), ou le sidechain de Live s’il est branché.
