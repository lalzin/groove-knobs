Merci ! C’est installé.

Dans Ableton Live : Réglages → Plug-Ins → Rescan. Crackle apparaît dans les effets audio : Plug-Ins → VST3 / Audio Units → LALZIN. Glisse-le sur une piste.

Astuce : mappe le knob sur ton contrôleur MIDI (mode MIDI Map d’Ableton, premier paramètre « Grain »).
